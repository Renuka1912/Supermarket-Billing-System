# Supermarket-Billing-System
I’m glad to present my project: Supermarket Billing System (Admin & Staff Panel) 🛒💻

This project is designed to streamline supermarket operations by providing separate functionalities for Admin and Staff, ensuring efficient management and smooth billing processes.

🔐 Admin Panel Features:
• Manage products (Add / Update / Delete)
• Category & supplier management
• Purchase and stock management
• Sales reports and analytics
• Dashboard with business insights

👨‍💼 Staff Panel Features:
• Fast billing system with live product search
• Cart management and automatic total calculation
• Discount and GST handling
• Multiple payment options (Cash / UPI / Card)
• Receipt generation and sales tracking

🛠️ Technologies Used:
• Frontend: HTML, CSS, JavaScript
• Backend: Python (Flask)
• Database:  MySQL

🎯 Through this project, I gained hands-on experience in:
• Full-stack web development
• Role-based authentication (Admin & Staff)
• Database design and management
• Building real-time billing systems
